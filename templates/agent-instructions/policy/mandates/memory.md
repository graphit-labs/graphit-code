
# Memory
Before answering a question or resolving a knowledge gap at any stage, or capturing durable guidance, corrections or discoveries, read `{{ skill_name_memory }}` if it is not in context; then use its {{ brand_display }} MCP tools. For a new doubt about the system or a rationale, search `{{ mcp_tool_memory_search }}` with `filter.exclude_mandatory: true`.
Capture when it happens, not at the end: a correction or stated preference of the user or project (`correction`, `convention`), a decision and its reason (`decision`), a non-obvious discovery or business rule (`fact`), a procedure that worked (`skill`), an unresolved conflict (`tension`). At every checkpoint and before closing, sweep the work unit for anything the next session would otherwise rediscover; if it is confirmed and plausibly reusable, save it, since consolidation merges duplicates later. Update the existing subject (`{{ mcp_tool_memory_update }}`) before inserting (`{{ mcp_tool_memory_insert }}`). Writes exist only on an authorized Role: from Root, batch the decided items into one brief for the Scribe role.
