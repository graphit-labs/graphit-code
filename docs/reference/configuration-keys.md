# Configuration keys and defaults

This reference describes keys with current Rust consumers, not arbitrary names accepted by the
flat Config store. [Configuration](../guides/configuration.md) defines precedence, JSON typing,
scope, secrets and inspection. Public null is invalid; a wrong winning type fails rather than
using a lower layer. Defaults below apply when absent, unless stated otherwise.

## Scope and environment capture

Ordinary precedence: Command > Environment > Project > Global > Distribution > consumer default.
An explicit false/zero/empty is still present. Whole lists/objects replace lower layers. Key syntax
uses ASCII dotted identifiers (128-byte bound, at most 16 segments); `auth`, `providers`, `accounts`
and obsolete AI/grammar aliases are outside ordinary configuration.

Mechanical names use `GRAPHIT_` plus uppercase key with dots changed to `__`. This names a potential
environment input, not an implicit feature. Consumers capture only requested keys. App's default
`environment_keys()` registers Hub limits, module switches, `agent`, `ai.cli`, `mcp.host`, `mcp.port`,
`data.local_graph`, `task.browser`, `githooks`, `ast.scip.parsers` and `ast.scip.version`. Additional stored/inline
keys or explicitly requested inspection may be captured at their own boundary; `config get`
success does not prove an unconfigured arbitrary environment key was consumed by a daemon.
Use a persisted setting or explicit `-c` for other supported controls and verify its real consumer.

`--global-dir` / `GRAPHIT_GLOBAL_DIR` is bootstrap selection, not a key. Native tool variables such
as `GRAPHIT_AST_SCIP_PULL_POLICY` do not follow the dotted-key double-underscore spelling.
Auth provider/account fields use their dedicated CLI/schema, not `config set auth...`.

## Core, interfaces and services

| Key | Type / absent default | Effect and capture boundary |
|---|---|---|
| `githooks` | Object event → ordered string array; absent inherits, `{}` disables inherited command hooks | Root field in project/global documents. Native Git 2.54+ dispatcher; whole object replaces lower layers, command strings never use CSV. [Contract](../guides/git-hooks.md) |
| `agent` | Native binding; default OpenCode | Specialized explicit/project/ambient/membership selection; not ordinary fallback to any installed executable |
| `ai.cli` | String; selected binding if absent | Installation-only completion executable; captured at Ask attachment, restart to reattach |
| `unit.id` | ASCII ID, 1–128 bytes, alphanumeric at both ends, with `._-` permitted internally; generated IDs are ULIDs | Attribution, not remote identity or authorization |
| `client.secret` | Secret string; generated by installation ensure | Installation-only event salt; inspection redacts value |
| `ui.auth.cookie_encryption_key` | Accepted redacted installation secret | No consumer in current opaque-handle Rust Browser; not session encryption/durability or Browser activation |
| `mcp.host` | String IP; `127.0.0.1` | Source listener capture at startup; remote binds require explicit deployment policy |
| `mcp.port` | u16; `0` | Zero binds an ephemeral actual port; use returned discovery/UI URL |
| `broker.allow_loopback_http` | Boolean; false | Explicit local-development transport exception where consumed |
| `task.browser` | Strict object; `providers` accepts CSV text or a string array; absent means no Browser configuration | Global/Distribution/Environment/Command only; Broker providers and authorization endpoint required |
| `daemon.models` | Strict object with `slots`; missing differs from `slots:[]` | Use `models install/select` for Global task slots; empty slots explicitly opts out |
| `models.idle_timeout_seconds` | Positive representable seconds; 300 | Global local embedding/rerank residency; active native work finishes before unload |
| `search.rerank` | Boolean; false | AST/Knowledge opt-in; per-request true/false overrides effective setting |

`models.embedding.id` and `models.rerank.id` have an installation scope policy but are not the
productive model-slot selector. Do not use them in place of `daemon.models` / `models select`.
`cli`, `ui.host`, `ui.auth.enabled`, `ast.scip.enabled` and arbitrary custom names do not create
features merely because the generic store can retain a public key. The known removed selectors `ai.embedding.provider/model/base_url/api_key/dimensions`,
`ai.rerank.provider/model/base_url/api_key`, `ai.agent_args`, `ai.agent_args.*`,
`ast.allow_native_grammars` and `ast.cluster` are rejected. Other unconsumed custom names do not
activate a feature.

### Module switches

All twelve are booleans. `modules.task`, `modules.memory`, `modules.ast`, `modules.knowledge`,
`modules.hub`, `modules.daemon`, `modules.sync`, `modules.embedding`, `modules.hooks` and
`modules.agent` default true. `modules.dream` and `modules.daemon_ui` default false.
The latter is environment/command policy rather than persistable Project/Global configuration.
A module switch is an orchestration input, not a grant or sufficient configuration for a service.
`modules.embedding=false` preserves CRUD/FTS while preventing embedding work; it does not disable
an independently explicit reranker. Rerank remains false unless enabled separately.

### Browser object

`providers` is a nonempty list of unique configured Broker provider names; `project_endpoint` is
the trusted PROJECT authorization endpoint. Provider topology must agree with Browser rules.

| Field | Default / validation |
|---|---|
| `public_origin` | Absent: actual bound origin; explicit value must pass origin/HTTPS validation |
| `knowledge_conversations` | false; enabling requires the configured Broker MCP resource |
| `allow_loopback_http` | false; only explicit local development |
| `login_timeout_ms` | 300000; positive representable interval |
| `session_lifetime_ms` | 3600000; positive representable interval |
| `refresh_margin_ms` | 60000; validated by the Browser duration policy |

Example for an already configured local development Broker, not production credentials:

```sh
graphit config --global set task.browser '{"providers":["dev-broker"],"project_endpoint":"http://127.0.0.1:8080/v1/project/access/authorize","allow_loopback_http":true}'
```

Use the Broker's real trusted endpoint/port/provider and its explicit loopback exception; restart
when changing captured listener/Browser topology. Production uses HTTPS/public origin and valid
OAuth/PROJECT setup. CORS and a selected URL do not bypass login or access.

### Model slot runtime

The strict `daemon.models.slots` entries carry `name`, task/service `selection`, bundle and
relative manifest, plus the task's `runtime` object. Prefer `models install/select` to construct
and validate them. The current product installer chooses `threads=ceil(available_parallelism/2)`
and `queue_capacity=8` for each local runtime; these are native execution defaults, not compile-job
limits or global machine quotas. The captured slot can explicitly configure its validated runtime.
Inference device/device ID belongs to the Local Auth service independently of embedding/rerank.
MRL dimensions come from the selected embedding manifest, not a nonexistent `models select --dimensions`.

## AST and compiler configuration

| Key | Type / default | Meaning |
|---|---|---|
| `ast.index_docs` | Boolean; false | Include the configured documentation directory in AST path selection; does not add a Markdown grammar |
| `ast.index_source` | Boolean; true | Persist selected file Source for exact readers |
| `ast.queries_dir` | Relative string; `.<brand>/ast/queries` | PROJECT extraction overrides |
| `ast.grammar` | CSV string; empty | Explicit extension/grammar selections, with backend selection validation |
| `ast.grammars_whitelist` | CSV string; empty | Restrict eligible grammars under profile selection rules |
| `ast.grammars_blacklist` | CSV string; empty | Exclude grammars under profile selection rules |
| `ast.scip.parsers` | CSV string; empty | `extension=image`; winning layer replaces list, empty clears it |
| `ast.scip.version` | String; `v1` | Maintained image compatibility alias, not artifact version or custom-image suffix |
| `ast.query.buffer_pool_bytes` | u64; 0 | Ladybug native pool default (~80% available memory); positive explicit bytes >=4096 |
| `ast.query.threads` | Positive integer; 2 | Native query-handle thread setting, not compile jobs |

SCIP is standard, not opt-in. `GRAPHIT_AST_SCIP_PULL_POLICY` defaults `always`; `missing` only pulls
if absent, `never` cannot fetch an absent image. These apply to normal Docker references including
custom registries; Docker owns its credentials. [AST extensibility](../guides/ast_extensibility.md)
defines profile fields, selectors, merge, custom-image IO/mounts/SCIP output and fallback errors.

## Knowledge settings

| Key | Type / default | Meaning |
|---|---|---|
| `knowledge.docs_dir` | Relative string; `docs` | Maintained documentation root |
| `knowledge.include_readme` | Boolean; true | Include root README under source selection rules |
| `knowledge.extensions` | CSV string; list below | Explicit document suffixes consumed by the compiler |

Default suffixes: `md,markdown,mdx,txt,adoc,rst,puml,plantuml,yaml,yml,json,proto,graphql,gql,wsdl,xml`.
`.wikiignore`, format/metadata settings and current physical/compilation fingerprints still apply.
An extension is not a promise that arbitrary binary content becomes Markdown. See
[Knowledge settings](../architecture/rust-knowledge-settings.md) for strict parsing and format rules.

## Dream

Dream needs both enabled module orchestration and `dream.enabled=true`, plus the selected scope's
real authority. It is opt-in, not activated by installing a completion executable.

| Key | Type / default | Meaning |
|---|---|---|
| `dream.enabled` | Boolean; false | Effective Dream execution opt-in |
| `dream.model` | Required nonempty string when enabled | Literal model for Dream |
| `dream.program` | Required nonempty string when enabled | Explicit completion program |
| `dream.agent` | Required Hub Agent artifact ID when enabled | Resolves the Dream Agent in the registry; current execution requires the Codex binding |
| `dream.agent_version` | Optional string | Concrete version of that Hub Agent artifact; omission uses the registry resolution contract |
| `dream.idle_timeout` | Positive seconds; 7200 | Human inactivity before eligible work |
| `dream.max_duration` | Positive seconds; 600 | Finite run deadline |
| `dream.retries` | u32; 2 | Existing failure/retry policy |
| `dream.backoff` | Positive seconds; 30 | Retry spacing |

Filesystem churn is not human activity. [Dream contract](../specs/dream_module.md) defines Memory
scope, fencing, proposal/application and recovery; no Task completion or arbitrary shell grant.

## Instruction publication

`agents.<binding>.instructions` is the strict persisted logical selection used by native publishers
(binding hyphens become underscores). It retains role rules, module skill aliases/bundles and
module-tool choices from explicit CLI publication options. PROJECT/Global storage follows the
actual destination. Omitted sync options reuse saved choices; raw overrides have their own
precedence. Do not persist rendered payloads, host paths or credentials in this object.
[CLI options](cli-options.md), [templates](../architecture/rust-agent-instruction-templates.md) and
[native Global instructions](../development/native-global-instructions.md) define the exact fields.

## Agent publication and instruction customization

`agents.<binding>.instructions` stores logical publication choices for managed roles, skills and
Coordinator sync. Binding hyphens become underscores in the key. Choices include the role/rule
selection, module skill aliases/bundles and effective tool names supplied through the corresponding
CLI options. Use [managed publication](../guides/cli_reference.md#managed-roles-and-module-skills)
for exact flags rather than constructing an unvalidated internal object. Omitted options reuse
saved choices; explicit options replace the selected choice. Project/global destination controls
which ConfigStore owns it. These choices do not contain rendered bodies or credentials.

Raw instruction customization is file-based, not another dotted-key namespace. PROJECT
`.<brand>/rules/` and Global `rules/` supply the documented Markdown template overrides. The
engine resolves Project > Global > selected Hub bundle > package defaults; selected invalid
content fails rather than falling through. `defaults/<entry>` can wrap the package default.
The [template engine](../architecture/rust-agent-instruction-templates.md),
[skills](../architecture/rust-skill-instructions.md) and
[policy templates](../architecture/rust-policy-instructions.md) define paths, variables, companions
and original-request validation. General `sync` publishes the selected instructions, agent hooks
and MCP configuration; it does not grant tool availability or upgrade artifact versions.

## Reload and verification

Inspection reports configured values/source, not a synthesized list of every default above.
`config --global get/list` reads only persisted Global and ignores Project/env/command values.
Model slots refresh through observed Global control changes; already admitted work retains its
capture. `ai.cli`, listeners and Browser attachment have their startup/attachment boundaries.
Changing configuration persistence alone does not prove an already running consumer applied it.
Check the corresponding service/response and concrete diagnostics. No command here implies a
legacy migration, environment scan, provider fallback, automatic artifact upgrade or new model TTL.
