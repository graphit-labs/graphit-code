# The brand directory separates versionable source from runtime and local binaries

## Status

Accepted and implemented on 2026-08-24.

Scope: `internal/brand`, `internal/dream`, `cmd/graphit/commands`, `.gitignore`.
Task log: `docs/tasks/map-project-brand-directory-writes.md`.

## Context

The local brand directory holds four different classes of content: shareable textual configuration, machine-specific native libraries, generated outputs, and operational state. Ignoring the entire directory would hide `rules/**` and `ast/queries/**`; ignoring only runtime would let parser binaries and old export/Dream defaults leak into Git.

The source of truth also needed to be single. `graphit init`, tests, and the checkout of the project itself cannot keep independent lists of patterns.

## Decision

The `.gitignore` block generated by `brand.GitignoreContent()` contains exactly these two trees, at any depth:

```gitignore
**/.graphit/runtime/
**/.graphit/grammars/
```

`rules/**` and `ast/queries/**` remain visible to Git because they are shareable project configuration. `grammars/{treesitter,antlr}/**` remains the local mechanism to add or customize parser libraries, but their binaries are platform-specific and not versioned by default.

Generated outputs now use `runtime/`: `graphit ast export` writes by default to `.graphit/runtime/ast/export/`, and Dream uses `.graphit/runtime/dream/`. Explicit overrides `--output` and `dream.reports_dir` remain user-controlled.

Paths have the following property:

| Tree | Property | Policy |
|---|---|---|
| `ast/queries/**` | textual parser configuration | versioned |
| `rules/**` | project-shared rule/skill | versioned |
| `grammars/{treesitter,antlr}/**` | local native library | ignored |
| `runtime/**` | generated output and machine state | ignored |

## Consequences

### Benefits

The boundary precisely represents ownership, not just the module that created the file. Queries and rules describe shareable repository behavior. Exports, reports, sentinels, read markers, caches, and locks are local results. Parser libraries are also local because they vary by OS and architecture; a shared grammar should be distributed as a Hub language artifact.

Centralizing patterns in the generator prevents `graphit init`, tests, and the project's own checkout from keeping divergent lists.

### Costs and migration

- The existing marked block is replaced idempotently on the next `graphit init` run; this repository was updated to the generator's current content.
- Legacy files in `.graphit/dream/` and `.graphit/ast/export/` are not moved or deleted automatically. Users can point overrides at them or migrate explicitly.
- Ignoring `grammars/` trades accidental portability for explicit distribution. Projects needing to share a library should publish it to the Hub, not force-commit a local binary.
