The operating loop

Context that compounds as the project evolves.

Each Graphit module does one job well. Together they give agents a reliable way to understand, remember, connect, and operate.

01 / UNDERSTAND

Map the code

Query symbols, callers, dependencies, imports, inheritance, complexity, and source through a structural graph.

02 / REMEMBER

Keep the why

Store corrections, decisions, conventions, and discoveries so the next session starts with project context.

03 / CONNECT

Compile the docs

Turn maintained documentation into a searchable wiki with provenance, confidence, and cross-references.

04 / OPERATE

Bring it to the IDE

Install the right rules, skills, MCP tools, languages, and shared artifacts for the active project and assistant.

Clear trust boundary

Local by default. Shareable when you choose.

Mutable code, docs, indexes, and memory sources stay on your machine. Optional S3-compatible storage can publish reusable artifacts across projects and teams.

  • Local coreNo hosted database is required for everyday operation.
  • Explicit sharingHub publishing and remote storage are configured separately.
  • Network-aware UIThe UI binds to loopback by default and is not an authentication layer.

Start with one binary

From repository to agent context.

Install Graphit, initialize the project for your IDE, then let the daemon keep indexes current.

curl -fsSL https://raw.githubusercontent.com/graphit-labs/graphit-code/main/install.sh | sh
cd your-project
graphit init --ide codex
graphit ui
irm https://raw.githubusercontent.com/graphit-labs/graphit-code/main/install.ps1 | iex
cd your-project
graphit init --ide codex
graphit ui
git clone https://github.com/graphit-labs/graphit-code.git
cd graphit-code
make install
graphit setup
