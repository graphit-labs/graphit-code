AST Graph Explorer

Built for blazing fast Go performance. Parses every file using Tree-sitter into LadybugDB. Query deterministic code structures with Cypher. Eliminates hallucinations by grounding answers in exact structural truths, and drastically reduces LLM token usage by passing only precise nodes instead of massive files.

Install in Seconds

Zero dependencies. Use GitHub Artifacts or compile via make.

# Download Pre-compiled Binary from GitHub Artifacts
curl -fsSL https://github.com/graphit-labs/graphit-code/releases/latest/download/graphit-linux-amd64 -o graphit
chmod +x graphit
sudo mv graphit /usr/local/bin/

# Configure & Init
graphit setup
graphit init --ide <antigravity|gemini|claude|cursor|kiro|codex|opencode>
# Download Pre-compiled Binary (Apple Silicon)
curl -fsSL https://github.com/graphit-labs/graphit-code/releases/latest/download/graphit-darwin-arm64 -o graphit
chmod +x graphit
sudo mv graphit /usr/local/bin/

# Configure & Init
graphit setup
graphit init --ide <antigravity|gemini|claude|cursor|kiro|codex|opencode>
# Download Pre-compiled Binary (PowerShell)
Invoke-WebRequest -Uri "https://github.com/graphit-labs/graphit-code/releases/latest/download/graphit-windows-amd64.exe" -OutFile "graphit.exe"

# Add graphit.exe to your PATH to run globally

# Configure & Init
.\graphit setup
.\graphit init --ide <antigravity|gemini|claude|cursor|kiro|codex|opencode>
# Compile manually. Requires: Go 1.23+, Node.js 22+, Make
git clone https://github.com/graphit-labs/graphit-code.git
cd graphit-code
make install

# Builds and installs the binary to /usr/local/bin/
