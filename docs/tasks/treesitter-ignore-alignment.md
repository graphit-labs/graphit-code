# Ignore treesitter vendored parsers (like ANTLR)

## Problema

The files are located in the directories of __INLINE_2__.
(Clojure, GraphQL, ObjC, R) are generated parsers for C by Tree-Sitter.
Vendorized because their respective packages do not publish official Go bindings.

The GitHub Linguist identified it as **Pawn** due to the extension `.inc`.
Misleadingly inflating language statistics in the repository's stats.

Moreover, those files were not being ignored by the AST indexer or in the indexing process.
GoLangCI-Lint, unlike the files generated by ANTLR that already had those
Exclusions.

Solution

### `.astignore`
Adicionada regra `internal/ast/treesitter/*/parser.c.inc` para excluir os
Vendorized index AST files. The `binding.go` (Go code)
integration continues to be indexed normally.

### `.gitattributes` (novo arquivo)
Criado com `linguist-vendored=true` para todos os `parser.c.inc`:
```
internal/ast/treesitter/*/parser.c.inc linguist-vendored=true
```
That causes the GitHub Linguist to exclude those files from its language calculation.
repository (the same effect of `vendor/`).

Aproveitado para marcar arquivos gerados do ANTLR (`.interp`, `.tokens`)
como `linguist-generated=true`.

### `.golangci.yml`
Added `internal/ast/treesitter` to the exclusion block `paths` of the
GoLangCI-Lint mirrors the treatment already in place for `internal/ast/antlr`.
