# Remove the duplicate source-text copy from the Lance files table

The final Linux store is 7.84GB, of which files.lance is 3.16GB for a 1.64GB source tree. buildFileRow stores source verbatim in the source column and again inside body for FTS, so the table pays about twice before indexes. Design one source owner that remains queryable by ast source and publishable to remote consumers while FTS still searches file contents and filenames/paths. Candidates include a compressed binary source column plus a non-duplicated FTS representation, or a published per-file compressed source store; do not simply remove source because Lance is currently the only queryable/published copy. Measure search recall, source latency, artifact size, and remote bundle behavior. Acceptance: file search/source semantics remain equivalent and files.lance/source artifact bytes fall materially on the Linux corpus.
