# Migrate ANTLR and Tree-sitter to Native Go (No WASM)

## Summary
Migrated both ANTLR (PL/SQL) and Tree-sitter parsers from WASM/Wasmtime to 100% native Go/CGO. Removed `wasmtime-go/v21` and `wazero` dependencies, deleted the separate `tools` module, and updated the hub language installation logic to install only query YAML configurations.

## Details
1. **Native ANTLR PL/SQL Integration**:
   - Copied the PL/SQL parser Go files from `tools/antlr-go-grammars/plsql/parser/` to `internal/ast/grammars/antlr/plsql/`.
   - Updated package name to `plsql`.
   - Moved SLL/LL parsing strategy helper functions into `internal/ast/grammars/antlr/plsql/parser_sll_ll.go`.
   - Updated `internal/ast/antlr_adapter.go` to invoke the native parser and convert `antlr.Tree` to `wasmantlr.TreeNode` directly (completely bypassing JSON serialization).

2. **Native Tree-sitter CGO integration**:
   - Cleaned up the local C parser files: instead of copying C files for all languages, imported 15 standard Tree-sitter languages directly from `github.com/smacker/go-tree-sitter/...` packages.
   - Imported Dart from `github.com/UserNobody14/tree-sitter-dart/bindings/go` and XML from the official `github.com/tree-sitter-grammars/tree-sitter-xml/bindings/go` package.
   - Instantiated both Dart and XML dynamically via `sitter.NewLanguage(...)` on their respective C bindings, eliminating any need for local C/scanner files or custom headers.
   - Updated `internal/ast/treesitter_adapter.go` to dispatch parsing requests to these native packages.

3. **Cleanup of WASM/Wasmtime**:
   - Deleted the obsolete `internal/ast/wasmts/` and `internal/ast/grammar_loader.go` files.
   - Deleted the obsolete `internal/ast/wasmantlr/engine.go` file.
   - Removed `replace` directives and the obsolete `./tools/` directory.
   - Removed `wasmtime-go` dependency from `go.mod` and ran `go mod tidy`.
   - Updated the `Makefile` to simplify `bundle_ast` and remove all zig and go wasip1 WASM compile targets.

4. **Hub Language Artifact Changes**:
   - Modified `internal/hub/service.go` (`Install`, `preUninstallHook`, and `Link` blocks) to ignore `.wasm` files and only install query YAML configuration files.

5. **Lint & Vet Fixes**:
   - Updated the `vet` target in the `Makefile` to exclude the autogenerated ANTLR PL/SQL parser (`internal/ast/grammars/antlr/plsql`).
   - Refactored `treesitter_adapter.go` to use `ParseCtx` instead of deprecated `Parse` method, resolving a staticcheck warning.

6. **Default Query YAML Verification and Dart ABI Alignment**:
   - Pinned the `tree-sitter-dart` commit to `ac0bb849ccd1` in order to use a version compatible with Tree-sitter ABI version 14 (supported by `github.com/smacker/go-tree-sitter`).
   - Created a local CGO binding package `internal/ast/treesitter/dart/` incorporating the C/C++ parser/scanner sources from the pinned commit, bypassing the incompatible ABI 15 Go bindings in newer external releases.
   - Updated `internal/ast/treesitter_adapter.go` to import the local `dart` binding.
   - Updated `scratch_inspect_grammars.go` to use the local `dart` package.
   - Refactored failing default query YAML configurations in `internal/ast/queries/`:
     - [cpp.yaml](internal/ast/queries/cpp.yaml): Modified namespaces pattern to support `namespace_identifier` and `nested_namespace_specifier`.
     - [dart.yaml](internal/ast/queries/dart.yaml): Modified fields pattern to use a simplified, query-compatible `initialized_identifier` pattern.
     - [javascript.yaml](internal/ast/queries/javascript.yaml): Removed invalid `graph_label` property from the `exports` relation query.
     - [sql.yaml](internal/ast/queries/sql.yaml): Changed `*_statement` node types to native C nodes (`create_function`, `create_table`, `create_view`), and matched function/view/table names through `object_reference name: (identifier)`.
     - [swift.yaml](internal/ast/queries/swift.yaml): Removed non-existent node types (`struct_declaration`, `enum_declaration`) and updated structs/enums/classes queries to match `class_declaration` using keyword-based anonymous node constraints.

7. **Cleanup and Obvious Comments Removal**:
   - Removed redundant doc comment from the `GetLanguage` function in `internal/ast/treesitter/dart/binding.go` according to comment guidelines.
   - Deleted the temporary bare clone directory `/tmp/temp_dart_git`.
